I. DESCRIPTION
The course is to provide learners
●   IoT Introduction & Concepts
●   IoT protocols
●   Iot database management
●   IoT platforms
●   IoT graphical user interface
●   IoT application development for mobile
●   IoT physical servers and cloud offerings

II. MAIN OBJECTIVES
After successful completion of the course, the students shall be able to:
●   Understand the IoT concepts.
●   Understand the networking basics required to set up IoT applications.
●   Understand various IoT communication protocols
●   Using the IoT application development tools.
●   Implement IoT applications.
