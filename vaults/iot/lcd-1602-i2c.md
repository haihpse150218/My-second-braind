# LCD 1602 qua I2C

> Tóm tắt 1 câu: LCD 1602 = màn hình **16 cột × 2 dòng** ký tự; gắn module I2C phía sau thì chỉ cần 4 dây (VCC, GND, SDA, SCL) và năm lệnh để hiện chữ — **giao diện người dùng** đầu tiên của môn.

## 💡 Ý chính

Nối **truyền thống** cần 6 chân digital (RS, E, D4–D7) + biến trở chỉnh tương phản. Module I2C (chip PCF8574) gói hết vào 2 dây SDA/SCL — đổi 6 chân lấy 2, giá thêm vài nghìn đồng.

| Lệnh | Làm gì | Ở đâu |
|---|---|---|
| `lcd.init()` hoặc `lcd.begin()` | khởi tạo | `setup()` |
| `lcd.backlight()` | bật đèn nền | `setup()` |
| `lcd.setCursor(x, y)` | con trỏ tới cột `x` ∈ 0…15, dòng `y` ∈ 0…1 | trước mỗi `print` |
| `lcd.print("Text")` / `lcd.print(bien)` | ghi chuỗi/số từ vị trí con trỏ | |
| `lcd.clear()` | xoá màn hình, con trỏ về (0,0) | |

```cpp
#include <Wire.h>
#include <LiquidCrystal_I2C.h>
LiquidCrystal_I2C lcd(0x27, 16, 2);   // địa chỉ từ i2c_scanner, 16 cột, 2 dòng
void setup() {
  lcd.init(); lcd.backlight();
  lcd.setCursor(0, 0); lcd.print("Dr Minh");
  lcd.setCursor(0, 1); lcd.print("Xin chao cac ban");
}
void loop() {}
```

## 🧩 Trực giác

LCD là **tờ giấy 32 ô**, mỗi ô một ký tự; `setCursor` chọn ô, `print` viết từ ô đó sang phải. Viết quá 16 ký tự thì phần thừa **biến mất** (không tự xuống dòng).

## ⚠️ Điều dễ nhầm

- Màn hình sáng nhưng **không chữ** hoặc toàn ô vuông: sai địa chỉ I2C (chạy scanner — [[giao-tiep-i2c]]) hoặc tương phản chưa chỉnh (biến trở xanh sau module).
- `lcd.print(27.5)` in `27.50`; muốn 1 chữ số thập phân: `lcd.print(temp, 1)`.
- In số thay đổi độ dài (`9.8` → `10.2`) để lại ký tự cũ: in kèm khoảng trắng `"  "` hoặc `clear()` trước — nhưng `clear()` liên tục gây nhấp nháy, chỉ ghi đè vùng cần.
- Ký tự tiếng Việt với `LiquidCrystal_I2C` thường: ra rác — phải dùng thư viện Multilingual.
